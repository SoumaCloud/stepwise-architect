# Rust command guide

Run commands through the skill's `scripts/stepwise.sh`, using its absolute installed path. In Claude Code, `${CLAUDE_SKILL_DIR}` is substituted in the skill body. The guide below abbreviates the launcher as `stepwise`; preserve its absolute path when running commands.

Read-only commands:

```sh
stepwise demo
stepwise status --project "/absolute/product"
stepwise advise --project "/absolute/product" --stage review --task "Compare a review workflow for my existing stack"
stepwise research --project "/absolute/product" --task "Validate this product idea"
stepwise compare-costs --file "/absolute/costs.json"
stepwise catalog
```

Write commands, when the requested work authorizes saving project context:

```sh
stepwise init --project "/absolute/product" --file "/absolute/profile.json"
stepwise update-profile --project "/absolute/product" --file "/absolute/revised-profile.json"
stepwise remember --project "/absolute/product" --file "/absolute/decision.json"
stepwise recipe --project "/absolute/product" --file "/absolute/recipe.json"
```

Every command returns JSON on success. Errors go to stderr and return a nonzero exit status. JSON inputs can use `--file -` to read stdin. Never interpolate untrusted user text into shell commands. Use the host's file-writing tool to prepare JSON or pass it as stdin safely.

## Profile

```json
{
  "name": "My SEO SaaS",
  "description": "Weekly reports for small businesses",
  "existingTools": ["existing-assistant", "github-actions", "postgres"],
  "requirements": ["Commercial use allowed", "Backups before launch"],
  "constraints": {
    "monthlyBudget": 100,
    "currency": "USD",
    "noNewSubscription": true,
    "localOnly": false,
    "sensitiveData": false
  }
}
```

`update-profile` replaces the whole profile. Read the current profile and preserve unchanged values first. Decisions and recipes are retained. The next advice command uses the updated requirements immediately. `.stepwise` is plain local JSON, compatible with the older Node bridge. Keep it out of Git and never store secrets or customer records.

## Decisions and recipes

Each uses an object with `title` and `body`. The body should include evidence URLs and dates, rationale, alternatives, assumptions and the review trigger. For a recipe, use a reusable prompt with expected inputs, actions and a success check. IDs and timestamps are generated by Rust.

## Cost input

Supply `currency`, `workload`, `current`, `proposed` and optional `switchingCost` and `qualityAcceptable`. Each scenario has `basis` set to `forecast` or `observed`, with an `items` array. Fixed items have `name`, `kind: "fixed"` and `monthly`. Metered items have `name`, `kind: "metered"`, `quantity`, `rate` and `per`. A quantity of 20,000,000 at a rate of 5 per 1,000,000 costs 100 in the selected currency. All rates are user inputs; no vendor prices are fetched.

## Catalog updates

Use `--catalog "/absolute/catalog.json"` to select a reviewed local catalog. The command validates its schema, source URL format, metadata and stages. Source content still needs the assistant's scrutiny. This overrides the compiled catalog for that invocation only. There is no background updater and no automatic modification of the skill.
