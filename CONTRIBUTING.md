# Contribute

For the Rust skill, run `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings` and `cargo test --locked`. For the optional Node bridge, run `npm ci --ignore-scripts`, `npm test` and `npm run check`. Keep changes focused on a real builder task. Commit Cargo.lock for reproducible application builds.

For a catalog update, supply an official source, access date, supported deployment, billing assumptions and relevant limitations. Unknown data should remain `null`. Do not add affiliate-based ranking, unverified discounts or unsupported compliance claims. Re-run representative project scenarios after changing recommendations.

For feedback, include your current stage, existing tools, constraints, suggestion received, expected behavior and observed result. Remove credentials, private repository content and customer records.

Do not commit `.stepwise/`, `.env`, API keys or generated `node_modules/`. See SECURITY.md for private vulnerability reporting guidance.
